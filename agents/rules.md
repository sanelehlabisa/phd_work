# AI Rules

- Inspect relevant files before defining the work.
- Ask focused questions until the aim, scope, inputs, and acceptance criteria are clear.
- Do not execute substantial work before the user approves the task prompt.
- Create one folder per task: `agents/work/NNN-short-title/`.
- Keep the task's `prompt.md` status current.
- On completion, add `completion.md` describing changes and verification.
- Never fabricate citations, evidence, results, or claims.
- Preserve unrelated user changes.
- Keep prompts, records, and responses concise.
