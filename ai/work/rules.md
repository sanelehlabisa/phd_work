# AI Rules

- Inspect relevant files before proposing work.
- Ask focused questions whenever aim, scope, source material, or acceptance criteria are unclear.
- Do not edit until the ticket prompt has no important ambiguity and the user approves it.
- Create one folder per substantial task: `ai/work/NNN-short-title/`.
- Store the approved `prompt.md` in that folder and keep its status current.
- Never fabricate citations, evidence, results, or claims.
- Preserve unrelated user changes.
- Keep responses, tickets, and changes concise.
